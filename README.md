# Personal Portfolio Website

A responsive personal portfolio website built to showcase my projects, technical skills, and web development work completed during my Codomax internship.

## Live Demo
[View Live Portfolio](https://aroosakousar4-dev.github.io/portfolio/)

## Features
- **Responsive Design:** Adapts cleanly across mobile, tablet, and desktop screens.
- **Projects Showcase:** Highlights key development work and live links.
- **Interactive UI:** Smooth navigation and dynamic interactions powered by JavaScript.
- **Contact Section:** Easy ways to connect and reach out.

## Technologies Used
- **HTML5** – Semantic structure and layout
- **CSS3** – Custom styling, Flexbox/Grid, and responsive media queries
- **JavaScript** – DOM manipulation and interactive features
